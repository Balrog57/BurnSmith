tsMuxeR as BurnSmith carries it
===============================

tsMuxeR.exe is the build that BDMV Author 0.1.133 ships (https://github.com/blenheimears/bdmvauthor, Apache-2.0):
justdan96/tsMuxer at commit c6b1186 (Apache-2.0, see tsMuxeR-LICENSE.txt) with two changes made by BDMV Author
(third_party/tsmuxer/BDMVAUTHOR-VENDORING.md in that repository):
  - S_HDMV/IGS accepted as an input (Interactive Graphics stream, type 0x91, PID 0x1400+, written in the CLPI and MPLS);
  - insertSEI no longer writes initial_cpb_removal_delay = 855000: the delay comes from the stream's own HRD.

It was built with MSYS2 UCRT64 and needs four libraries, carried beside it unchanged:
  - libgcc_s_seh-1.dll, libstdc++-6.dll : GCC runtime libraries, GPL-3.0 with the GCC Runtime Library Exception 3.1 (below);
    sources: https://gcc.gnu.org, GPL-3.0: https://www.gnu.org/licenses/gpl-3.0.txt
  - libwinpthread-1.dll : mingw-w64 winpthreads (licence below); sources: https://www.mingw-w64.org
  - zlib1.dll : zlib (licence below); sources: https://zlib.net
